# Employee Performance & Salary Analysis

## Project Overview
An end-to-end data analytics project using SQL and Power BI to analyze employee performance, salary distribution, departmental workforce, and country-wise performance.

## Tools Used
- MySQL 8.0+
- Power BI
- SQL
- DAX

## SQL Skills
- Joins
- Aggregate Functions
- Subqueries
- CTEs
- Window Functions
- RANK and DENSE_RANK
- LAG and ROW_NUMBER
- CASE Statements

## Power BI Analysis
- Employee headcount
- Department-wise employee distribution
- Gender distribution
- Average salary by department
- Country-wise performance score
- Performance comparison (2024–2025)
- Salary analysis

## Business Objective
To identify workforce trends, salary patterns, and employee performance insights to support data-driven HR decisions.
